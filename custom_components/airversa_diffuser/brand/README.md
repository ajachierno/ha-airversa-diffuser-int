# Brand assets

HACS looks for `icon.png` in this folder.

Replace this folder's `icon.png` with the Airversa logo:
- `icon.png`     square, transparent PNG, 256x256
- `icon@2x.png`  square, transparent PNG, 512x512 (optional but recommended)

For the icon to render inside Home Assistant itself (not just pass HACS),
also submit the same assets to https://github.com/home-assistant/brands
under `custom_integrations/airversa_diffuser/`.
